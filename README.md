# Del Costo al Precio de Venta

Landing de ventas del ebook de Montenegro & Asociados. Sitio estático (un solo `index.html`), pensado para GitHub Pages.

Configuración: bloque `CONFIG` al inicio del script de `index.html` (precio, enlaces de Hotmart y Shopify, enlace de WhatsApp de la comunidad, IDs de Meta Pixel y TikTok Pixel, testimonios).
